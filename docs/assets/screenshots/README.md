# GUI screenshot assets

This directory contains four placeholder images used by the repository README and the PDF documentation. Replace each placeholder with a real PNG screenshot while keeping the same filename and a similar 16:9 aspect ratio:

- `main_window.png` - Parameters tab with device, geometry, target, and optimization settings.
- `live_optimization.png` - Simulation tab with progress, logs, and live loss curves.
- `results_browser.png` - Results tab with masks, reconstructed fields, and generated files.
- `checkpoint_resume.png` - Model loading, graceful stopping, and continuation controls.

Recommended image size: 1600 x 900 pixels or larger. Remove personal paths, machine names, and confidential data before committing screenshots.
