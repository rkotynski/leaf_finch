# GUI screenshot assets

These images are used by the repository README and the PDF documentation. Project homepage: https://github.com/rkotynski/leaf_finch

- `main_window.png` - Parameters tab with device, geometry, target, optimization, reconstruction, and output settings.
- `live_optimization.png` - Simulation tab with progress, logs, and live loss curves.
- `results_browser.png` - Generated binary masks for the phase-shifted DMD patterns.
- `results_reconstructed.png` - Reconstructed intensity and phase in the circular off-axis observation region.
- `finch_psf.png` - FINCH PSF obtained from the complex hologram by Fresnel backward propagation.

Recommended image size: 1600 x 900 pixels or larger where practical. Remove personal paths, machine names, and confidential data before committing screenshots.
