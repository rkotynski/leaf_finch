# GUI screenshot assets

The screenshots in this directory are used by the repository README and the PDF documentation. They intentionally show the default English interface and should remain in English. Keep the filenames when replacing an image:

- `main_window.png` - Parameters tab with language/device selection, geometry, target, and optimization settings.
- `live_optimization.png` - Simulation tab with progress, logs, and live loss curves.
- `results_browser.png` - Generated binary DMD masks.
- `results_reconstructed.png` - Reconstructed observation-plane intensity and phase.
- `finch_psf.png` - Fresnel reconstruction / FINCH PSF.

Recommended image size: 1600 x 900 pixels or larger. Remove personal paths, machine names, and confidential data before committing screenshots.
